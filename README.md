# Confidence-Aware Multimodal CNN (CAM)

## Overview

This project presents a Confidence-Aware Multimodal Convolutional Neural Network (CAM-CNN) for intelligent uterine disorder prediction by integrating ultrasound images and structured clinical data.

The model combines image-based deep learning with patient clinical features to improve diagnostic accuracy and provide reliable predictions.

---

## Features

- Multimodal Deep Learning
- Ultrasound Image Analysis
- Clinical Data Integration
- Confidence-Aware Prediction
- Performance Evaluation
